# 深度清理面板增强优化方案

## 1. 优化目标
当前深度清理面板具备一键扫描/一键清理功能，但缺乏暂停/继续、实时进度条、扫描信息反馈等常用功能，导致用户体验不流畅。优化方案旨在对标业界主流（腾讯360安全卫士、CCleaner 等）的深度清理设计，实现完整的安全清理流程体验。

## 2. 优化方向

### 2.1 暂停/继续功能
- **功能**: 支持用户在长时间扫描/清理过程中主动暂停并继续
- **UI 设计**: 中间悬浮层全屏覆盖（半透明灰色 + 加载动画），显示"暂停中..."状态
- **交互**: 首次点击"暂停"显示暂停层，再次点击"继续"恢复
- **进度保留**: 暂停后保留进度计算，后续继续时从上次进度恢复

### 2.2 实时进度条
- **位置**: "深度清理"面板顶部的进度条，紧跟"一键扫描"按钮上方
- **样式**: 水平进度条，高度 4px，圆角 2px
- **状态**: 分为扫描（蓝灰色）和清理（绿色）两种颜色
- **动态**: 跟随扫描/清理过程实时更新

### 2.3 扫描信息面板
- **功能**: 扫描/清理过程中的详细信息面板
- **内容**: 
  - 实时进度百分比
  - 当前正在处理项描述（如"正在清理微信缓存"、"正在扫描注册表项 X/Y"）
  - 预计完成时间（基于当前速度计算）
  - 状态图标（√/⏸/⟳/⚠ 等）
- **位置**: 紧跟进度条之后，大块区域（高度 ~120px）
- **状态**: 分为四种状态显示样式（进行中/完成/暂停/错误）

### 2.4 扫描项详细列表（可选）
- **功能**: 支持展开/折叠扫描到的具体项列表
- **内容**: 
  - 项目名称（图标+文本）
  - 大小（如"45.2 MB"）
  - 状态（待处理/处理中/已完成/跳过）
  - 安全级别徽章（🔒/⚠️/🔴）
- **位置**: 面板下方，小尺寸卡片形式
- **交互**: 点击项目条目聚焦进度条，查看详细信息

### 2.5 智能分步处理
- **功能**: 根据扫描进度智能切换处理策略
- **应用场景**:
  - 扫描完成后自动显示详细项列表
  - 多个高风险项时先弹出安全确认再继续
  - 遇到错误时自动暂停并显示错误详情

### 2.6 行业标准对标设计
- **图标**: 采用系统预设图标，统一设计语言
- **颜色**: 采用高对比度配色方案
- **动画**: 流畅的过渡动画，减少用户等待感知
- **响应式**: 支持暗黑模式，自动调整配色

## 3. 技术实现方案

### 3.1 架构扩展
- **新类**:
  - `ScanProgressBar`：继承 `wxPanel`，自定义绘图实现进度条
  - `ScanInfoPanel`：显示扫描状态信息的控件
  - `ScanListView`：可扩展的扫描项列表
- **状态机**:
  - `Scanning` / `Paused` / `Cleaning` / `Completed` / `Error`
  - 支持从任意状态进入暂停，暂停支持继续/取消
- **事件机制**:
  - `EVT_DEEP_CLEAN_PROGRESS`：实时进度事件
  - `EVT_DEEP_CLEAN_PAUSE`：暂停/继续事件
  - `EVT_DEEP_CLEAN_ITEM_UPDATE`：单项进度更新事件

### 3.3 数据流设计
1. **扫描/清理线程** → `ScanProgressEvent` → `DeepCleanPanel`
2. **UI 线程** → 更新 `ScanProgressBar`、`ScanInfoPanel`
3. **暂停控制** → 控制线程休眠/继续
4. **错误处理** → 显示错误面板，提供重试/跳过选项

### 3.4 性能优化
- **线程控制**:
  - 使用 `std::atomic<bool> pauseFlag` 控制暂停
  - 实现进度快照保存/恢复
  - 支持从暂停位置继续
- **UI 流畅性**:
  - 使用 `wxAnimation` 实现平滑过渡
  - 控制每帧绘制时间，保持60fps
- **内存管理**:
  - 控制单帧渲染项目数量
  - 实现虚拟滚动列表

### 3.5 安全与健壮性
- **状态同步**:
  - 所有UI更新在主线程进行
  - 避免并发访问共享数据
- **错误恢复**:
  - 实现自动重试机制
  - 提供用户可控的操作（跳过/继续/取消）
- **用户体验**:
  - 实现强制确认危险操作
  - 提供清晰的错误信息和恢复路径

## 4. 交互流程设计

### 4.1 一键扫描流程
1. 点击"一键扫描"
2. 进度条显示扫描中动画
3. 信息面板显示"正在扫描各类缓存..."
4. 扫描过程中，用户可点击"暂停"按钮
5. 暂停后显示全屏暂停层
6. 用户可继续扫描或取消
7. 扫描完成自动显示扫描结果摘要

### 4.2 一键清理流程
1. 用户选择待清理项
2. 点击"一键清理"
3. 创建系统还原点
4. 显示进度条和信息面板
5. 显示正在清理的项
6. 支持暂停/继续
7. 清理完成后显示完成弹窗

### 4.3 错误处理流程
1. 扫描/清理过程出现错误
2. 显示错误信息面板
3. 提供重试/跳过/取消选项
4. 错误恢复后继续处理

## 6. 风险评估

### 6.1 技术风险
- **风险**: 长时间运行的线程可能影响UI流畅性
- **应对措施**: 使用 `std::atomic` 和合适的线程控制策略，确保UI线程优先

### 6.2 性能风险
- **风险**: 大规模列表显示可能影响性能
- **应对措施**: 实现虚拟滚动和分页加载

### 6.3 用户体验风险
- **风险**: 复杂的功能可能导致用户混淆
- **应对措施**: 简化交互流程，提供清晰引导

## 一、IceClean 现有能力清单

| 模块 | 当前功能 |
|------|---------|
| **扫描器(12类)** | 系统临时文件、Windows更新缓存、浏览器缓存、缩略图缓存、崩溃转储、休眠文件、预读取文件、回收站、驱动备份、开发缓存(WinSxS)、日志文件 |
| **清理器(7类)** | 文件清理、浏览器清理、休眠清理、回收站清理、DISM组件清理、隐私清理(Cookie/历史/表单)、注册表清理 |
| **迁移器(5类)** | 微信、QQ、Steam、开发缓存、用户文件夹(文档/下载/图片等)、自定义文件夹 |
| **优化器(3类)** | 启动项管理、服务优化、计划任务优化 |
| **分析器** | 磁盘空间分析(矩形树图)、进程分析(分组/安全评级) |
| **安全机制** | 系统还原点、白名单保护、安全评级(Safe/Caution/Dangerous)、操作日志 |
| **GUI** | 仪表盘、深度清理、智能迁移、磁盘分析、启动优化、设置、关于 |

## 二、对标 360 核心功能差距分析

### A. 核心缺失功能

| # | 功能 | 差距等级 | 说明 |
|---|------|---------|------|
| 1 | 实时保护/监控 | 🔴致命 | 无任何形式的实时监控 |
| 2 | 病毒/木马查杀 | 🔴致命 | 无恶意软件检测能力 |
| 3 | 软件管家(卸载/升级) | 🔴重大 | 无软件卸载管理 |
| 4 | 驱动管理 | 🟡中等 | 仅有驱动备份扫描，无更新/安装 |
| 5 | 网络优化 | 🟡中等 | 无任何网络相关功能 |
| 6 | 弹窗拦截 | 🟡中等 | 无 |
| 7 | 文件恢复 | 🟡中等 | 无 |
| 8 | 右键菜单管理 | 🟡中等 | 无 |
| 9 | 定时清理 | 🟡中等 | 无定时任务 |
| 10 | 系统备份/还原 | 🔴重大 | 仅有还原点创建 |

### B. 现有功能能力不足

| # | 功能 | 差距 |
|---|------|------|
| 11 | 注册表清理 | 🔴重大 - 仅3类，深度不够 |

| 13 | 启动优化 | 🟡中等 - 缺延迟启动等 |
| 14 | 浏览器清理 | 🟡中等 - 支持浏览器少 |

| 17 | UI/UX | 🟡中等 - 美观度/动效一般 |
| 18 | 云能力 | 🔴重大 - 无 |

## 三、分阶段提升计划

### 🏗️ 第一阶段：补齐核心短板（1-2个月）

> 目标：从"能用"升级为"好用"，完善清理工具基本盘

| # | 任务 | 优先级 | 预估工时 | 状态 |
|---|------|--------|---------|------|
| 1.1 | 注册表清理深度扩展 | P0 | 2周 | ✅ |
| 1.2 | 隐私清理扩展 | P0 | 2周 | ✅ |
| 1.3 | 软件卸载管理 | P0 | 1.5周 | ✅ |
| 1.4 | 定时清理任务 | P1 | 1周 | ✅ |
| 1.5 | 右键菜单管理 | P1 | 1周 | ✅ |

#### 1.1 注册表清理深度扩展
- 新增：共享DLL无效引用、字体/帮助文件缺失引用、MRU历史记录
- 新增：COM组件无效项、ActiveX/TypeLib无效项
- 新增：安装程序残留、MUI缓存、环境变量无效路径
- 扩展 RegistryCleaner 的 RegistryInvalidItem::Type 枚举
- 扩展 RegistryCleaner 的扫描方法

#### 1.2 隐私清理扩展
- 新增类型：最近文档记录、运行历史、搜索记录、剪贴板记录、跳转列表
- 扩展应用支持：Edge/Chrome/Firefox 完整清理
- 新增：Office最近文件、WinRAR/7-Zip历史、迅雷/IDM下载记录
- 扩展 PrivacyType 枚举和 BrowserPrivacyPaths

#### 1.3 软件卸载管理
- 读取注册表卸载项(Uninstall键)
- 显示安装信息(名称/版本/大小/日期/发布者)
- 支持静默卸载、批量卸载、残留清理
- 新增 SoftwareUninstaller 类和 UninstallPanel

#### 1.4 定时清理任务
- 基于 Windows 计划任务 API 实现定时扫描+自动清理
- 支持每日/每周/每月
- 清理后自动关机/休眠
- 集成到 SettingsPanel

#### 1.5 右键菜单管理
- 扫描注册表右键菜单项
- 分类显示(文件/文件夹/桌面/驱动器)
- 启用/禁用/删除、备份恢复
- 新增 ContextMenuManager 类和 ContextMenuPanel

## 五、关键建议

1. **坚守定位**：聚焦 "C盘清理+系统优化" 差异化赛道，做深做精
2. **第一阶段最关键**：注册表深度清理 + 隐私扩展 + 软件卸载是用户感知最强的功能
3. **安全防护慎入**：病毒查杀投入产出比低，以轻量防护为切入点
4. **工程化先行**：扩展功能前先补齐测试体系和操作回滚机制
5. **云端能力**：长期看，云端白名单/规则库是持续价值的关键

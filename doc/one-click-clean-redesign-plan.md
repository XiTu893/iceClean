# 「一键清理」体验重构方案（360 模式）

> 制定日期：2026-08-20
> 说明：对已落地的深度清理「一键清理」页进行二次重构，参照 360 安全卫士 / 腾讯电脑管家 / CCleaner 的"傻瓜化 + 高级设置"模式。
> 本文仅为方案，确认后再实施。

---

## 一、背景与目标

### 1.1 现状（本轮已落地的一键页）

深度清理页新增了「一键清理」标签页：顶部「一键扫描 / 一键清理」按钮 + 分组勾选卡片（安全项默认勾选、谨慎/危险项需确认）。

**已达标**：聚合扫描、安全/危险分级、还原点+注册表备份、清理后反馈。

**差距（用户反馈的痛点）**：
1. 仍是一个"卡片列表"，对小白用户不够"傻瓜"——逐个勾选的心理负担仍在。
2. 入口不突出——放在标签页里，没有"大按钮 + 一个数字"的仪式感与反馈。
3. 高级能力（逐项精细控制、白名单、自定义）与普通流程混在同一屏，应分层。

### 1.2 目标

参照 360 的"一键体检/一键清理"模式，打造：
- **傻瓜化主流程**：一个醒目的主按钮 → 自动一次搞定（扫描→展示一张"体检报告"→一键清理），默认只动安全项。
- **分层体验**：普通用户看到结果与风险提示，点一下就完成；高级用户可展开「高级设置」逐项精细控制。
- 覆盖 **系统 / 注册表 / 隐私 / 软件缓存** 四大类，全部走同一个"一键"。

## 二、业界模式分析

| 产品 | 一键形态 | 麻雀式反馈 | 高级设置 | 对 IceClean 的可映射点 |
|------|---------|-----------|---------|----------------------|
| **360 安全卫士** | PC体检（计分圆环）→ 一键修复；一键清理整合"清理垃圾+痕迹+部分注册表"默认推荐项 | 体检分、问题数、风险分级 | "清理垃圾/清理痕迹"等详情页逐类操作；支持自定义/恢复 | **大按钮+圆环得分+一键修复**；默认推荐项整合；高级入口分离 |
| **腾讯电脑管家** | 全面体检 → 一键修复；垃圾清理"扫描→立即清理"，无风险项默认勾选 | 修复数、可清理量 | 分类详情、深度清理需二次确认 | 无风险默认勾选、深度确认 |
| **CCleaner** | 健康检查(Health Check) 一键分析 → 一键清理 | 可清理空间、待清理项 | Classic/Custom Clean 逐分类勾选 | 一键健康检查入口 + 经典分类模式并存 |
| **FluentCleaner** | 扫描一次 → 一键清理 | 扫描结果清单 | 分类下拉、右键白名单 | 简单主流程 + 分类明细 |
| **BleachBit** | 勾选→预览→删除 | 预览清单 | 分类树、命令行 | 预览确认 |

**提炼出的 3 条业界铁律**（360/腾讯/CCleaner 高度一致）：
1. **主干极简、次干丰富**：首页只放一个主按钮和一个结果数字；全部细节收进二级页。
2. **默认安全、可见风险**：安全项自动选中即清；危险项要么默认排除、要么弹窗明示。
3. **清理可追溯**：清理前还原点/备份、清理后按类汇报释放量、操作留痕。

## 三、目标体验设计

### 3.1 页面结构（深度清理页顶部改为一次大区，替代当前"卡片列表"）

```
┌─────────────────────────────────────────────────────┐
│  深度清理                                            │
│  需管理员权限。操作前自动创建系统还原点，注册表单独备份。  │
├─────────────────────────────────────────────────────┤
│                                                     │
│              ┌──────────────────┐                   │
│              │   ( 大号圆环按钮 )  │   ← 一键扫描      │
│              │    90 │ 健康分    │                   │
│              └──────────────────┘                   │
│  预计可释放  12.8 GB    ·    待清理 24 类/658 项        │
│                                                    │
│  [ ⚡ 一键清理 ]   [ 高级设置 ▾ ]                      │
│  （安全项自动清理；谨慎/危险项会先征求您的确认）          │
├─────────────────────────────────────────────────────┤
│  （下方保留 4 个原始标签页 = 高级模式）                 │
└─────────────────────────────────────────────────────┘
```

### 3.2 三步主流程

**① 一键扫描（大圆环按钮）**
- 点击后圆环进度动画，后台跑系统容量探测 + 注册表扫描 + 软件缓存 + 隐私探测（复用现有 Scanner/RegistryCleaner/SoftwareCacheScanner）。
- 完成后：圆环显示"健康分"（0–100，由可清理量/危险项权重估算，纯提示性）。
- 下方一行大字：`预计可释放 12.8 GB · 待清理 24 类 / 658 项`。
- 危险项计数单独显示：`其中含 3 项高风险操作（需确认）` 黄/红提示。

**② 一键清理**
- 默认执行：**安全项自动清理**（软件缓存、隐私痕迹、无效注册表的"安全子类"…）。
- 若勾选了谨慎/危险项 → 弹一个对话框逐条列明（名称+影响+备注），用户确认后执行。
- 进度圆环展示进行中的分类与已释放量；全程后台线程，不卡界面。

**③ 结果报告**
- 完成页（结果卡片）：`总计释放 X GB` + 按分类拆分（系统 / 注册表 / 隐私 / 软件）+ 成功/失败项。
- 附带"下次建议"与"查看日志"入口；一键关闭回到概览。
- 自动联动刷新仪表盘磁盘信息与最近操作。

### 3.3 高级设置（折叠面板 / 弹出页）

满足高级用户与控制欲，但默认收起：

| 能力 | 说明 |
|------|------|
| 分类明细勾选 | 系统4项、注册表12类、隐私13类、软件N个缓存——逐项勾选、显示容量/数量 |
| 风险筛选 | 只看安全 / 只看谨慎 / 只看危险；一键切换 |
| 默认策略 | 可改：安全项是否自动清、谨慎项默认勾选策略、危险项是否跳过 |
| 记忆上次选择 | 记住用户勾选偏好，下次一键扫描自动套用 |
| 白名单/排除 | 跳转已有的白名单设置 |

入口设为显眼的 `[高级设置 ▾]`，展开后是面板（同页展开或右侧抽屉），**不离开主流程**。

### 3.4 与现有四标签页的关系

- 原「系统清理 / 注册表清理 / 隐私清理 / 软件专清」4 个标签页保留，作为"高级模式/分类精细操作"，位于一键区下方。
- 一键区与高级页共享同一份扫描数据（本次已实现数据共享机制，复用）。

### 3.5 构成与组件

```
src/gui/panels/DeepCleanPanel.cpp        # 重构：顶部一键区 + 保持 4 标签页
  ├─ QuickCleanOverviewView（新，或并入面板）  # 大圆环 + 健康分 + 主按钮 + 结果报告
  ├─ AdvancedSettingsView（新，或并入面板）    # 折叠面板：分类明细/风险筛选/记忆
  └─ 复用：CreateQuickScan/Clean 能力（本次已写）
src/core/                                 # 复用现有 Scanner/Cleaner，无需新核心模块
```

> 说明：优先在 DeepCleanPanel 内以控件组合实现（YAGNI，不新建面板文件）；若后续"一键"要出现在首页仪表盘，再抽独立组件。

## 四、分阶段实施

| 阶段 | 内容 | 工作量 |
|------|------|--------|
| **A：一键区视觉重构** | 大圆环按钮（自绘/或 Dial 控件）、健康分、概览大字、主按钮 | 2–3 天 |
| **B：一键清理编排收口** | 安全项自动清清单+危险项确认清单规范化；结果报告卡片 | 1–2 天 |
| **C：高级设置面板** | 折叠面板：分类明细勾选、风险筛选、记忆上次选择、默认策略 | 2 天 |
| **D：打磨** | 圆环动效、文案、白名单跳转、错误兜底 | 1 天 |

## 五、风险与对策

| 风险 | 对策 |
|------|------|
| 圆环/动效过度、破坏简洁 | 仅"扫描中进度 + 健康分"两种动画，克制（遵循项目简洁原则） |
| 一键清理覆盖面过大误伤 | 危险项一律确认；安全项定义收敛（沿用三级安全标识 + 白名单 50+ 路径） |
| 健康分被当作真实安全评级 | 明确标注"参考值"，避免误解 |
| 扫描耗时（DISM/注册表） | 后台线程 + 进度 + 可取消；分类渐次出现而非等全部完成 |
| 用户找不到高级设置 | 主按钮旁常驻 `[高级设置 ▾]`，且四标签页仍在 |
